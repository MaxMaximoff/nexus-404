# Публикация изменений

Перед каждым push этого проекта обязательно выполнить `npm run ship` из `app/`.

Порядок: закоммитить исходники, выполнить `npm run ship`, закоммитить обновлённую
сборку `app/dist/`, затем сделать push. Сборка должна ссылаться на коммит исходников,
из которого она собрана. Подробности — в `DEPLOY.md`.
